# APK Maker

A starter Android APK Maker project.

## What this version does
- App name and package name input
- Add Text preview
- Add Button preview
- GitHub Actions workflow for building a debug APK

## How to use on GitHub
1. Create a new GitHub repository named `APK-Maker`.
2. Upload all files from this project.
3. Open **Actions**.
4. Run **Build APK** (or push to `main`).
5. Download the generated APK from the workflow's **Artifacts**.
